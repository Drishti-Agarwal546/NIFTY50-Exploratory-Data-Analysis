# NIFTY 50 Exploratory Data Analysis

## Project Overview

This project presents an Exploratory Data Analysis (EDA) and Statistical Analysis of NIFTY 50 historical stock market data from 2014 to 2024.

The analysis focuses on understanding the statistical characteristics, trends, distributions, variability, and relationships among the major stock market variables.

The project uses Daily, Monthly, and Yearly NIFTY 50 datasets to perform a comprehensive exploratory and comparative analysis.

---

## Dataset

The project includes three datasets:

- Daily NIFTY 50 Historical Data (2014–2024)
- Monthly NIFTY 50 Historical Data (2014–2024)
- Yearly NIFTY 50 Historical Data

The main variables used in the analysis include:

- Open Price
- High Price
- Low Price
- Close Price
- Trading Volume

---

## Analysis Performed

### 1. Data Loading and Preprocessing

The datasets were loaded and examined for:

- Missing values
- Data inconsistencies
- Data types
- Duplicate observations
- Outliers
- General dataset structure

Appropriate preprocessing techniques were applied before performing the statistical analysis.

---

### 2. Descriptive Statistical Analysis

Descriptive statistics were calculated to understand the central tendency and dispersion of the data.

The analysis includes:

- Mean
- Median
- Mode
- Minimum
- Maximum
- Range
- Variance
- Standard Deviation
- Quartiles
- Skewness
- Kurtosis

---

### 3. Comparative Analysis

A comparative analysis was performed across different time frequencies:

- Daily Data
- Monthly Data
- Yearly Data

The major price variables were also compared to understand differences and variations in stock market behaviour.

---

### 4. Data Visualization

Various visualizations were used to explore the data, including:

- Line plots
- Histograms
- Box plots
- Distribution plots
- Comparative plots
- Trend plots

These visualizations help identify patterns, variability, outliers, and overall market behaviour.

---

### 5. Normality Analysis

Normality tests and graphical techniques were used to examine whether the selected variables follow a normal distribution.

The analysis helps determine the appropriate statistical interpretation of the data.

---

### 6. Hypothesis Testing

Statistical hypothesis testing was performed to examine significant differences between groups and variables.

The project includes:

- One-Way ANOVA
- Two-Way ANOVA

These tests were used to investigate whether statistically significant differences exist across different groups and time periods.

---

### 7. Trend Analysis

Trend analysis was performed to examine the long-term behaviour of the NIFTY 50 index.

The analysis focuses on identifying:

- Long-term trends
- Market growth and decline patterns
- Cyclical movements
- Irregular variations
- Major market fluctuations
